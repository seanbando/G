## Key
**Source codes**
| Code | What | Where to get it |
|---|---|---|
| **MAP** | Dark teal/near-black map, amber routes + pins, timestamp card in corner | Build: Google Earth Studio (free) → grade dark, or After Effects / GEOlayers. Same template all video. |
| **CARD** | Text card: typewriter timestamp, Anton caps label, counter, chapter card | Build in editor (Premiere/CapCut/AE). |
| **DOC** | Real document, push-in + amber highlight sweep | FBI Vault / FBI.gov "Famous Cases", DOJ OPR report on Jewell (1997), plea agreements and DOJ press releases (2005), Rudolph's April 2005 statement, newspaper archives (AJC July 30, 1996). |
| **PHOTO** | Real archival photo, slow push-in or parallax | Wikimedia Commons / Library of Congress / FBI / BOP first (public domain). News-agency photos: license, or short editorial use. **Check rights per photo.** |
| **CLIP** | Real archival video, 3–8s, set up → play → break down | Gov/court sources first. News clips: crop or blur logos, no baked-in music, keep short and talk over them. |
| **REC** | Recreation still or short loop (AI / 3D / stock), no real faces: silhouettes, backs, hands, objects | AI image/video tool or stock. Only show what the record supports. |
| **STOCK** | Generic footage (forest, night town, acorns, etc.) | Pexels / Pixabay (free) or licensed stock. |

**Motion:** PUSH = slow push-in · PULL = slow pull-out · PAN · PARALLAX (photo split into layers) · FLY = map camera move between pins · DRAW = route line draws itself · SWEEP = highlighter sweep · SNAP = quick zoom/punch-in.
**Text:** every CARD, name tag, label, counter, quote and map label **types on with the typewriter effect + keystroke SFX** (style sheet §8). Not repeated in each row.
**Transitions:** cut unless noted. **FADE** = fade to black + chapter card (chapters only). **HIT** = cut on a music/SFX hit.
**Music beds** (licensed only): **A** night tension (low drone + pulse) · **B** investigation (ticking, steady) · **C** somber piano/strings · **D** woods (wind, sparse low strings) · **SILENCE** only once (#84).
